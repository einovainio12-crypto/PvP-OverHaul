PvP Overhaul — browser upload kit for Fabric 26.3

Your screenshot already shows build.gradle, gradle.properties, settings.gradle, gradlew, gradlew.bat, gradle/wrapper and scripts. Keep those files at the repository root. This kit adds the missing source and lets you create the hidden configuration files directly on GitHub.

1. Extract this ZIP.
2. Open your GitHub repository root. Choose Add file > Upload files.
3. Drag the src folder INSIDE Batch-1 into the upload box. Commit changes.
4. Repeat for the src folder INSIDE Batch-2, then Batch-3, committing each batch. Each batch has at most 80 files. They all merge into the same src tree. Upload the src folders, not the Batch folders. Use a browser that supports folder drag-and-drop.
5. At your repository root choose Add file > Create new file.
6. In the filename field type: .github/workflows/build.yml
7. Open workflow-build.yml.txt from this kit in a text editor. Copy ALL its contents into the GitHub editor. Commit changes. GitHub creates the directories from the filename path. Create this workflow LAST, after all three source batches.
8. Open Actions > Build Fabric 26.3. Open the successful run and download its artifact. Install pvp-overhaul-0.1.0.jar with Fabric API on Fabric Minecraft 26.3.

OPTIONAL: CODESPACES
Create these files with Add file > Create new file, copying the matching visible template contents:
.devcontainer/devcontainer.json  <- optional-hidden-file-templates/codespaces-devcontainer.json.txt
.devcontainer/Dockerfile         <- optional-hidden-file-templates/codespaces-Dockerfile.txt
.gitignore                      <- optional-hidden-file-templates/gitignore.txt
.gitattributes                  <- optional-hidden-file-templates/gitattributes.txt
Only .github/workflows/build.yml is required to enable the Actions builder. The Codespaces files are for the optional workspace.

CHECK THE RESULT
The root should show src, .github, gradle, scripts and your existing root build files.
Under src you should have main/java, main/resources and client/java.
Under .github/workflows you should have build.yml.
