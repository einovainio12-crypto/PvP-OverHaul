BUILD INPUT ART — v0.8.3

Eighty-six textures/*.png files are the latest user-supplied 16x16 PNGs.
The additional quiver.png is a generated transparent sprite based on the
supplied leather-quiver thumbnail; original item designs are retained.
The resource generator copies them unchanged into the mod's item textures.
The sprites are seven battleaxes (wood, stone, copper, iron, gold, diamond,
netherite), seven knives, twelve arrows, and sixty stone/copper/iron/gold/diamond/netherite ranged-weapon states. pixil-frame-5.png maps to stone_battleaxe.png.

User-provided art retains its original rights; code licensing does not
relicense that art. Other icons are generated by pixel_art.py. Shields use
supplied originals under scripts/shields and shield_assets.py.

Knife_wood/stone/copper/iron/gold/diamond/netherite.png each maps to
textures/<material>_knife.png. No resizing or pixel modification is performed.

QUIVER GENERATION PROMPT (built-in image generation; downsampled with nearest
pixel sampling to 16x16 for the actual game asset):
Use case: background-extraction and stylized-concept. Asset type: Minecraft vanilla-style quiver inventory item sprite. Use the provided image as the exact design reference: diagonal brown leather quiver from bottom-left toward top-right, dark charcoal loop strap on its left, three white feathered arrows emerging from the top-right, warm tan leather front and darker brown bottom. Produce one clean sprite isolated on a truly transparent background, no white backdrop, no ground shadow, no text or labels, no extra props. Match the chunky hard square pixel art and vanilla palette of the reference, preserve its silhouette and arrangement. Use a crisp logical 16 by 16 pixel grid with hard nearest-neighbor pixel squares, fill the square canvas with a one-pixel transparent margin. White arrow fletching stays opaque. Flat inventory sprite, no gradients, no anti-aliasing, no perspective 3D rendering. This is to be downsampled to a 16x16 PNG game texture.

BROWSER KIT: sprites_packed.json bundles the exact eighty-seven art-input PNGs
as base64. generate_resources.py decodes it before checking loose PNGs, so
older browser uploads cannot override current packed sprites. Complete-project
keeps the loose editable originals and does not need the packed file.
grappling_arrow.png is the supplied pixil-frame-0_10(3).png, copied unchanged;
its in-flight model reuses Minecraft's native fishing bobber renderer.
