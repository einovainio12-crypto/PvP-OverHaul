# Punchy and Punchy Moves

Install the Fabric 26.3 versions of Punchy! and/or Punchy! Moves separately.
Neither is required by PvP+. No third-party mods or animation packs are bundled.

Punchy uses exact item mappings for 172 PvP+ weapons, bows and shields, including
compatibility materials. Knives use sword styling, battleaxes axe styling,
hammers mace styling, scythes hoe styling, halberds/spears spear styling and
flails fishing-rod styling. Bows, crossbows and shields use their matching kinds.
These mappings use the animations of your selected Punchy profile.

Punchy Moves gets 34 original mirrored clips and item-specific bindings for
swings, heavy strikes, sweeps, jabs, blocking, bow/crossbow actions and flail
casting. They do not require Fluid & Foolish. A full-body movement pack can still
supply walking, running, emotes and other actions. No global camera, keybind,
vanilla-item or movement animation settings are changed.

This is animation support, not a change to damage, reach, cooldowns or textures.
Custom mechanics still run in PvP+. Pack-controlled effects for custom throwing,
Lunge, Riptide and flail reeling need in-game verification; not every external
pack or mod combination has been tested. Higher-priority resources can override
assets/punchy/compat/pvpoverhaul.json and the corresponding punchy_moves files.

Validation: all 172 rules and 34 clips accepted by the actual Punchy Moves 1.0.7
format/animation parsers; resource and reference checks passed. Punchy mappings
follow the published itemSpecific/kind format (Punchy 3.1b reference inspected).
A graphical game session and a full Gradle build have not been run for this update.
