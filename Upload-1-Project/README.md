# PvP+

PvP+ is a Fabric mod for Minecraft 26.3 that adds tiered weapons, ranged combat
equipment and a few extra movement options. It is still under active
development, so combat balance and multiplayer compatibility will change.

The mod's command and resource namespace is `pvpplus`. For example:

```text
/give @s pvpplus:hellfork
/enchant @s pvpplus:throwable 1
```

The Fabric mod ID remains `pvpoverhaul` for loader compatibility.

## Install

You need:

- Minecraft Java Edition 26.3
- Fabric Loader 0.19.5 or newer
- Fabric API 0.162.0+26.3 or newer
- Java 25

Put the PvP+ JAR in the `mods` folder on both the server and every client.
Use the same mod version everywhere.

GitHub Actions builds are in the Actions tab. Open a successful build and
download the JAR artifact. The regular JAR is named like
`pvp-plus-0.10.21.jar`; do not install the `-sources.jar`.

## What's included

- Wood through netherite bows, crossbows, knives, battleaxes and shields
- Native spears, plus Throwable and Pole Jump enchantments
- Halberds, hammers, scythes and flails
- Custom arrows, grappling arrows and a slingshot
- Bows with Zoom, Target Lock and Dead Eye abilities
- Crossbow magazines and tier-based ammunition rules
- Cleaving, Impact, Throwability and other combat enchantments
- Elytra Boost, Overload and Aerodynamics
- Double Jump and Speed boot enchantments
- A nine-slot quiver with a radial selection menu
- Dragon Scale wolf armor and Elytra-style wolf flight
- A six-tick perfect-block parry window for every vanilla and mod shield
- Craftable tridents and Dragon Scale items
- Fletching-table upgrades and arrow crafting
- Optional material support for Advanced Netherite, Enderite, Rose Gold and
  compatible modpacks

### Default controls

| Key | Action |
| --- | --- |
| Z | Hold to zoom |
| R | Target Lock |
| V | Dead Eye |
| B | Elytra Boost or Overload (Overload takes priority if equipped) |
| G | Pole Jump |
| C | Open or use quiver selection |
| H | Swap with an inventory, offhand or worn sheath |

You can change all of these under Minecraft's Controls menu. Weapon abilities
usually require the matching tier and enchantment.

## Building from source

The repository has a Gradle wrapper, so you do not need to install Gradle.

```bash
./gradlew build
```

The JARs will be written to `build/libs`.

For a client or local server:

```bash
./gradlew runClient
./gradlew runServer
```

The server task creates `run/eula.txt`. If you use it, review and accept the
Minecraft EULA yourself.

Windows:

```powershell
.\gradlew.bat build
.\gradlew.bat runClient
.\gradlew.bat runServer
```

## GitHub Actions

Push a change to the repository to start the `Build Fabric 26.3` workflow.
You can also run it manually from the Actions page.

The build scripts generate models, recipes, translations and resource files
before validating and packaging the mod. Java and Python source files are kept
separate from their generated resources.

## Compatibility

This is a work in progress. PvP+ hooks combat, enchantments, projectiles,
rendering and Elytra movement in several places, and those interactions need
real multiplayer testing.

A few known expectations:

- Use the same PvP+ version on the server and all clients.
- Optional material support does not bundle the source mod or its assets.
- Existing worlds should be backed up before major updates.
- PvP+ item and enchantment IDs now use the `pvpplus` namespace. Update old
  `pvpoverhaul`/`pvpplushell` commands and datapacks; old saved item IDs are not
  automatically migrated.
- Removed items do not become replacement items automatically.
- Resource files can be regenerated by the build scripts; make persistent
  texture or datapack edits in the supplied source files/scripts.

See [TESTING.md](TESTING.md) for what has been checked and what still needs
in-game testing. See [CHANGELOG.md](CHANGELOG.md) for recent changes.

## Project layout

- `src/main/java` - mod code
- `src/main/resources` - metadata and static resources
- `scripts/` - resource generation and validation
- `src/test/java` - small balance and dependency-free checks
- `.github/workflows/` - build automation
